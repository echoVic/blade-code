# 🗡️ Blade Code

> A multi-surface AI coding assistant built for real engineering work

- 🌐 **Multi-surface runtime**: CLI, Web UI, Headless, and ACP share one runtime
- 🤖 **Provider Catalog**: unified model metadata, protocols, and credentials
- 🛠️ **Rich tooling**: 20+ built-in tools for file/search/shell/Git/Web
- 🔒 **Secure & controllable**: four permission modes + tool allow/deny lists
- 🔗 **MCP protocol**: unlimited extensibility
- ⚡ **Skills & Hooks**: dynamic prompts and tool hooks
